# 领域文档

本仓库使用单一上下文的领域模型。

## 开始探索前先阅读

- 仓库根目录的 `CONTEXT.md`。
- `docs/adr/` 下相关的 ADR。

如果其中任一位置不存在，直接继续，无需特别说明。只有术语或决策已经明确时，domain-modeling 工作流才会创建或扩展这些文档。

## 文件结构

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

## 使用术语表中的词汇

在 Issue 标题、重构提案、假设或测试名称中使用领域概念时，采用 `CONTEXT.md` 中定义的术语。不要改用术语表明确标记为避免使用的同义词。

如果需要的概念尚未收录，请重新判断该术语是否属于本项目，或在 domain-modeling 工作流中记录这一缺口。

## 标记 ADR 冲突

如果拟议工作与现有 ADR 冲突，应明确指出冲突，不要静默覆盖已有决策。
