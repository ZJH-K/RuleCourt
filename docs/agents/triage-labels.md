# Triage Labels（分流标签）

| 标准角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 Issue |
| `needs-info` | `needs-info` | 等待提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或独立领域核验 |
| `wontfix` | `wontfix` | 不会处理 |

Skill 提及某个标准角色时，使用本表对应的 GitHub label。
